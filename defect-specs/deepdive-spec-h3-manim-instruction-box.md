The curator endpoint already reads a directive from the request body (run_curator.py:5220 — directive / instructions / custom_directive), but in the fresh path (episode 249 + force_regen) it is NEVER passed on: design_clip_artifact is called without it, and the directive is used only in the legacy else-branch.
manim_fresh_design.design_clip_artifact(transcript, title, body_duration, catalog, genai_mod, prior_equations, clip_num) takes NO directive/instruction parameter.
The beats worker (_h2_run_design_group) and manim_retrigger POST only ep / clip_num / force_regen / transcript / title — no directive field.
The below-player surface branches on has_beats (renderClipSurface): the Manim panel renders ONLY when a Manim artifact exists; otherwise the Mosaic-only template renders. An instruction box placed only in the Manim panel would be invisible exactly when a clip has no Manim yet.

The render-only path (same storyboard, redrawn) is force_regen=False. A directed design must therefore travel with BOTH Design this clip and Retrigger Manim-only, or a later retrigger would silently discard the user's instruction.

## PART A — PER-CLIP DESIGN INSTRUCTION BOX (in the Manim panel)

A1. The below-player surface is ALWAYS the Manim panel for the active clip (renderClipSurface no longer branches on has_beats; the Mosaic-only template goes entirely — see B5). When the clip has a Manim, the panel shows what it shows today (title / equation-or-anchor / status / stage count). When it has none, the panel shows "No Manim yet" plus the box and the Design button below — never a bare error line.
A2. Add ONE textbox in the Manim panel, under the status line, labelled as a design instruction for this clip's Manim (placeholder: "Instruction for this clip's Manim — e.g. make this an anchor, or use the thermal-time equation"). This is a design instruction, not feedback and not a chat. One box per active clip; it is NOT a per-beat box and NOT an episode-wide box.
A3. The box is per-clip and persistent: switching clips shows that clip's last directive, prefilled from the storyboard's stored design.directive (empty when never directed). The text stays in the box after a design — it is the clip's standing design instruction. Text typed but not yet submitted is NOT carried to another clip (switching clips re-renders the panel from the clip's stored directive).
A4. Wiring — all three hops, both fresh-cast entry points:
(a) Page: designArtifacts('clip') and switchClipToManim() read the box value and include it as directive in their POST JSON.
(b) Beats server: /api/beats/design_artifacts (clip scope) carries the directive onto the job, and the design worker forwards it in its curator POST. /api/beats/manim_retrigger forwards it in its curator POST. Episode-scope design ("Design artifacts", all 21 clips) IGNORES the box — the box is per active clip.
(c) Curator: the fresh path (ep 249 + force_regen) passes the directive into design_clip_artifact as a new directive parameter (default None). The directive is no longer dropped on the floor.
A5. The fresh design HONORS the directive — deterministically, and never by inventing an equation:

"anchor" (e.g. "make this an anchor", "anchor only") forces kind anchor. Reported as directive-forced.
Names an equation (e.g. "use the thermal-time equation") → match the directive words against the episode-page catalog (topic / normalized text) and pick the best-matching catalog member. The picked equation MUST be a catalog member. If nothing matches, degrade to anchor and REPORT it (never invent, never silently ignore).
Anything else → topic hint: boost catalog entries whose topic overlaps the directive words in the deterministic scorer, and pass the directive as an instruction to the Gemini choice too (the existing catalog-membership validation downstream is the backstop in both paths).
Empty directive → exactly the current behavior, no change.
A6. Reporting: the directive and how it was honored go into the design report (design_status, per job) AND into the storyboard's design dict (design.directive, design.directive_report, e.g. "directive-honored: forced anchor" / "directive-honored: equation <ref>" / "directive-unmatched: no catalog equation matched '<text>'; degraded to anchor"). The panel shows the last honored outcome under the box.
A7. Scope: the box affects the DESIGN call only. It does not touch the Mosaic side, the composite chrome, durations, or master assembly. It does not change what "Retrigger Mosaic-only", Patch, or Push do.
